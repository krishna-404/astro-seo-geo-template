Most SEO playbooks are written for a different buyer — a local business found
from a phone inside one city, or a consumer brand with a review count to grow.
The mechanics do not transfer. The principles underneath them usually do, once
you translate the buyer. This file is that translation, kept so the same
playbook is not re-argued every time it resurfaces.

## 1. The translation, not the dismissal

| The playbook's mechanic | For the business it was written for | For this site |
|---|---|---|
| Primary category on the listing | Which map-pack searches you appear in | Which **directory category** we list under — decides which listicles include us (`link-targets.md`) |
| Listing attributes | Filters buyers use | The **facets** buyers filter on in a directory: deployment, pricing model, integrations, region |
| Review count and velocity | Ranking factor | Directory ranking and listicle eligibility; a future metric until there are customers to ask |
| Posts cadence | Freshness signal | A changelog the site publishes, and posting where the ICP reads |
| Description tested in three versions | CTR on the listing | **Title and description tests on pages that rank and earn no clicks** — the funnel-ladder rung-2b test in /content-cadence |
| Service + city pages | Rank in each town | The market layer — one page per market, gated on market-specific data, never a template with the city name swapped in |
